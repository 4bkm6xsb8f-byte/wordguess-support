How WordGuess works

WordGuess is a free daily word puzzle: guess the hidden five-letter word in six tries. After each guess every tile is marked. A check mark means the letter is in the right spot, a triangle means the letter is in the word but in a different spot, and a dash means the letter is not in the word at all.

There is one shared daily puzzle. Everyone gets the same word on the same calendar day, and a new puzzle arrives at midnight in your own time zone. Puzzle #1 was 1 January 2026 and the number goes up by one every day, so the hints on this page change every day too.

How to use the hints

The hints run from gentle to strong. The vowel count (A, E, I, O and U) and the repeated-letter check narrow things down without giving away any letter. The first and last letters are bigger nudges. The full answer sits behind its own "Reveal answer" button, so you will never see it by accident.
